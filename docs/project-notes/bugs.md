# Bug Log

Tracks defects discovered in this repo with their root cause and fix. New entries go at the top, numbered `BUG-NNN`.

Suggested template:

```
## BUG-001 — short title

**File:** path/to/file
**Discovered:** YYYY-MM-DD
**Status:** Open | Fixed
**Branch:** feature/issue-N (if applicable)

### Description
What was observed.

### Root cause
Why it happened.

### Fix
What changed.
```
